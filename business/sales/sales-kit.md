# SNS投稿制作・運用代行 営業キット
（作成: 2026-07-02 ／ 用途: ココナラ出品・地元営業・ポートフォリオの原稿一式）

> ✅ 価格はココナラ実勢調査（2026-07）で校正済み。
> **実勢データ**: 単発の画像作成は「1投稿(5〜8枚) 1,500円」「1枚1,000〜1,500円」帯のレッドオーシャン。月8投稿30,000円のまとめプランも存在。運用代行はフリーランスで月1〜5万円、法人代理店で月10万円〜が相場。
> **結論**: 「画像作成屋」として出品すると1,500円の価格競争に巻き込まれる。**「構成・企画から設計する運用パートナー」として出品し、単発は入口・月間プランで回収**する。

## 0. ROI判断の結論（なぜこれを売るか）

| 案 | 初収益まで | 理由 |
|---|---|---|
| **投稿制作・運用代行 ←これ** | **1〜4週間** | 既存の制作パイプライン（フォーマット20種・制作ルール14・品質チェック16）をそのまま商品化できる。需要が既にある市場 |
| 歴史コンテンツ(米沢藩) | 6ヶ月〜 | 資産型。棚上げ。軌道に乗ったら「地元営業の名刺」として再開 |
| テンプレ販売 | 1〜3ヶ月 | 実績と発信ができてから棚に置く |

**戦略**: 最初の3件は実績づくり特価 → 評価が付いたら正規価格に値上げ。これがココナラの定石。

## 1. サービス設計（松竹梅）

### 🥉 ライト「投稿設計プラン」
- **内容**: ネタをいただければ、タイトル3案＋スライド構成案（枚数分の上・中・下指示）＋図解指定＋キャプション文を納品。デザインはお客様側で実施
- **納期**: 2営業日 ／ **価格**: 実績特価 2,000円 → 正規 5,000円（1投稿）
- **狙い**: 「デザイン1,500円」の競合と土俵が被らない**企画・構成の商品**。原価（時間）が極小

### 🥈 スタンダード「まるごと制作プラン」★主力
- **内容**: 上記＋Canvaでのデザイン制作まで（フィード投稿1本＝8枚完成品）
- **納期**: 4営業日 ／ **価格**: 実績特価 5,000円 → 正規 10,000〜15,000円（1投稿）
- **相場との位置**: 実勢1,500円帯より上。差別化は「構成設計＋制作ルール14項目＋品質チェック込み」であることを本文で明示（単なる画像作成でないと伝われば通る価格。伝わらなければ§2の本文を強化）
- **オプション**: +2,000円で投稿文のABパターン、+4,000円で類似2案

### 🥇 プレミアム「月間運用パートナー」
- **内容**: 月8投稿の企画→制作→投稿文まで＋月次ふりかえり（数値レポート）
- **価格**: 月額 30,000円（実績特価）→ 40,000〜50,000円（実勢: ココナラに月8投稿30,000円あり／フリーランス運用代行は月1〜5万帯）
- **狙い**: ストック収益。**ここが本命**。単発2件目の顧客に必ず案内する

## 2. ココナラ出品文（コピペ用・スタンダード版）

**タイトル（30字前後）**
> プロの制作ルールでInstagramフィード投稿作ります

**キャッチコピー**
> ネタを送るだけ。構成〜デザイン〜投稿文まで「保存される投稿」を一式納品

**本文**
```
【こんな方へ】
・投稿を作る時間がない
・何を投稿すればいいか毎回悩む
・デザインはできるが「構成」が自己流で伸びない

【私の強み】
企業SNSの制作現場で使われる「制作ルール14項目」と
「品質チェックリスト16項目」に基づき、感覚ではなく
型で作ります。フック（掴み）×トーン×構成の3軸で
20種類の投稿フォーマットから、あなたのネタに最適な
型を選定。AIも活用し、スピードと品質を両立します。

【納品物】
1. タイトル案 ×3（フックの型つき）
2. スライド構成案（1枚ごとの上段・中段・下段の設計）
3. 図解・写真の指定書
4. Canva完成データ（5〜10枚）
5. キャプション（投稿文）＋ハッシュタグ案

【制作の流れ】
ご購入 → ネタ・ターゲットのヒアリング（フォーム1枚）
→ 構成案ご確認 → デザイン制作 → 納品（修正2回無料）

【ご注意】
・薬機法等の専門領域は事前にご相談ください
・実績づくり期間のため先着3名様は特価です
```

**よくある質問（3つ登録）**
- Q: ネタが思いつかない → A: 業種を伺えば、ネタ出しからご提案します（+2,000円）
- Q: 修正は何回まで → A: 構成・デザイン各2回まで無料です
- Q: 投稿代行は可能？ → A: 月間プラン（準備中）でご対応します。お問い合わせください

## 4. ポートフォリオの構成（1枚もの・Canvaで自作）

載せる順番:
1. **Before/After**: 「ネタ1行」→「完成フィード10枚」の変換例（一番伝わる）
2. **制作システム図**: ネタ→3軸フィルタ→フォーマット選定→構成→品質チェック→納品（先日の図解の流用でOK）
3. **数字**: 「フォーマット20種／制作ルール14項目／品質チェック16項目／納期◯日」
4. **クライアントワーク実績**: 「金融系企業のSNS制作ルール策定・運用に従事」とだけ書く（※社名は出さない。契約上の確認が取れるまで匿名厳守）

## 5. デモ成果物サンプル（営業時にそのまま見せる用）

**お題**: 米沢の焼肉店「（仮）米澤亭」の集客投稿

- **選定フォーマット**: 数字型×ポジティブ×リスト構造（f_ranking系）
- **タイトル案**:
  1. 「米沢牛、部位で選ぶと世界が変わる｜プロが選ぶTOP5」
  2. 「知らずに頼むと損してる。米沢牛の部位、正解はこれ」
  3. 「地元民が本当に頼む米沢牛の部位、教えます」
- **構成（7枚）**: ①表紙(タイトル+肉写真) ②問題提起「いつも同じ部位頼んでない?」 ③〜⑥部位紹介(各: 上段=部位名/中段=写真+特徴図解/下段=おすすめの食べ方) ⑦まとめ+CTA「保存して来店時に見返してね」
- **キャプション**: 冒頭1行フック→本文→来店導線→#米沢グルメ #米沢牛 等10タグ

※これを実際にCanvaで7枚作れば、ポートフォリオのBefore/After素材が完成する（架空店舗なので権利問題なし）。

**やらないこと（重要）**: 歴史コンテンツ制作／新ツール導入／完璧なロゴ作り。全部「1件目の受注」の後。
