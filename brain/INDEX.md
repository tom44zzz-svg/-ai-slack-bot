# 第二の脳 — INDEX（AIの入口）

AIが作業前にここを読み、必要なページへ辿る。各行は1行要約。**制作・営業・意思決定の前に必ず参照する。**

出典思想: 「モデルの賢さより、自分の文脈をどれだけ読ませるか」。4層で蓄積する。

## 使い方（AI向け）
- 業務・制作・営業・戦略の相談を受けたら、**まず該当する entities / concepts を読む**
- 新しい事実（顧客情報・議事録・記事）→ `raw/` に原文のまま追加
- 新しい判断・学び → `concepts/` に追記、または既存を更新
- 矛盾・重複を見つけたら指摘する（勝手に消さず確認）

---

## entities/（具体的な対象）
- `entities/自分-屋号.md` … あなた自身の強み・語り口・提供価値
- `entities/クライアント-セゾンファンデックス.md` … 既存クライアント（金融系・制作ルールの出所）
- `entities/クライアント-GGG.md` … 園芸店3店舗のYT/IG運用支援（受注案件）。数値・勝ちパターン・競合・季節カレンダーの正本
- `entities/題材-米沢藩と上杉鷹山.md` … 歴史コンテンツの主題
- `entities/事業-禁書ノオト.md` … 自社YouTube/TikTok事業。3チャンネル構成・マイルストーン・制作サイクルの正本
- `entities/環境-Mac操作設定.md` … Karabiner(Caps→Hyper) × Hammerspoon × Rectangle × AutoRaise。ホットキー一覧と、Hammerspoonの`local`によるGC停止という定番の罠

## concepts/（抽象概念・戦略・学び）
- `concepts/出荷ファースト.md` ★最重要 … 準備でなく出荷が唯一のボトルネック、という診断
- `concepts/事業戦略-ROI順.md` … 稼ぎの3ルートと優先順位
- `concepts/価格戦略.md` … ココナラ実勢と値付けの方針
- `concepts/制作品質の原則.md` … フォトリアル6原則・極限起動・品質の型
- `concepts/ハーネスエンジニアリング.md` … 実装役×レビュー役を分け、実ブラウザE2Eで合否判定する自律開発の型
- `concepts/HeroUI-UIライブラリ.md` … 旧NextUI。React/Tailwindの高速UI。受注UIの出荷を速める道具

## raw/（原文置き場・改変しない）
- `raw/2026-07-05-second-brain-fable5.md` … 第二の脳の元記事（X投稿）
- `raw/2026-07-ハーネスエンジニアリング開発実況.md` … 自律開発実況の書き起こし（ハーネス設計の原文）
- `raw/2026-08-15-AIスロップ対策スキル4選.md` … **文章**のAIっぽさ。4スキルの比較（鍛える/守る/消す/測る）。portability test
- `raw/2026-08-15-モチーフ駆動AIデザイン.md` … **デザイン**のAIっぽさ。コンセプト→**モチーフ**→デザインシステムの3層。「最小十分情報」
- `raw/2026-08-25-Claudeデザインスキル7選.md` … 既製の Claude デザインスキル7セットのカタログ（GitHub URL つき）

> 📌 上記3本は**3部作**。共通する診断は「情報が足りない分をAIが平均で埋めるから、よくある形に収束する」。
> 対策は**判断・基準を先に与えること**。①が文章、②が考え方、③が既製の道具。

## learning/（AIエージェント習得の日課）
- `learning/curriculum.md` … 習得カリキュラム（L0〜L5の地図）
- `learning/progress.md` … 現在地・ストリーク・次テーマ（`/lesson` が毎日更新）
- 毎日 `/lesson` で1テーマ。半歩先を維持する

## log/（作業ログ・整理ループの記録）
- 日々の作業ログ。毎晩整理→毎週 concepts/entities に統合する

---

## メンテナンス・ループ（`/brain` コマンドで実行）
1. **毎回**: 重要な判断・学びが出たら log に残す
2. **毎晩**: log を entities / concepts に整理・統合
3. **毎週**: 矛盾・重複をチェック、INDEX を最新化
