# brain/ — 第二の脳

「使うほど賢くなる業務OS」。AIに毎回ゼロから考えさせず、蓄積した自分の文脈を読ませてから作業させるための知識ベース。

## 4層構造

| 層 | 中身 | ルール |
|---|---|---|
| `raw/` | 記事・議事録・メモ・顧客情報の**原文** | 改変しない。日付＋出典を頭に付ける |
| `entities/` | 顧客・競合・ツール・人物・題材など**具体的な対象**ごと | 1対象1ファイル |
| `concepts/` | 戦略・学び・パターン・考え方など**抽象概念**ごと | 判断の「なぜ」を残す |
| `INDEX.md` | AIの入口。各ページの1行要約 | 追加したら必ず更新 |
| `log/` | 作業ログ。毎晩→concepts/entitiesへ統合 | 統合済みは印を付ける |

## なぜ効くか
- コード → 自分の設計思想に沿う
- 文章 → 自分の語り口に近づく
- 提案 → 過去の顧客情報・意思決定に基づく
- リサーチ → 一度きりで終わらず資産化される

**特に効くのは「なぜその判断をしたか（意思決定ログ）」。** 知識より判断の理由が残っている人ほど、AIの返しが自分寄りになる。

## メンテナンス
`/brain` コマンドで、追加・整理・週次チェックを行う。

## 機密の扱い
- クライアントの機密具体情報（金額・個人情報・未公開情報）は **`business/deliverables/`（git管理外）** に置く
- brain/ に置くのは「AIに毎回読ませたい、公開しても問題ない文脈」に留める
- 機密を含むメモは `brain/private/`（`.gitignore` 済み）へ

## 注記
- Claude Code には自動メモリ機能もあるが、それは自動蓄積の補助。この brain/ は**人が意図して育てる、事業文脈の正本**。役割が違う。
