# AIエージェント習得カリキュラム — 時代の半歩先を行くための地図

毎日1テーマ。`/lesson` が進捗を見て次を選ぶ。**順番は現在地に応じて前後してよい**（既知はスキップ、弱点は補強）。
各テーマは「概念→なぜ半歩先か→あなたの事業でどう効くか→5分アクション→明日の予告」で届ける。

出典の骨格: 2026年の必須は **7つの設計パターン**（ReAct / Reflection / Tool Use / Planning / Multi-Agent Collaboration / Sequential Workflows / Human-in-the-Loop）＋ **MCP / A2A プロトコル** ＋ **マルチエージェントの本番運用**。

---

## L0 — 現在地把握（初回のみ）
- 0-1 自己診断：あなたが「できること/知らないこと」を10問で棚卸し → progress.md に記録

## L1 — 土台リテラシー（半歩先の"前提"）
- 1-1 AIエージェントとは何か（チャットとの決定的な違い＝自律・ツール実行・ループ）
- 1-2 パラダイム転換：「賢いモデル」より「読ませる文脈」（第二の脳の思想）
- 1-3 エコシステム地図：モデル / MCP / スキル / エージェントの4層
- 1-4 プロンプトの型：役割・制約・出力形式・採点基準
- 1-5 Human-in-the-Loop：どこで人が介在すべきか（自律度4段階）

## L2 — 7つの設計パターン（プロの共通言語）
- 2-1 ReAct（推論＋行動のループ）
- 2-2 Reflection（自己批判で出力を強くする＝破壊者）
- 2-3 Tool Use / Function Calling
- 2-4 Planning（先に計画→実行＝plan mode / 勝利条件ファースト）
- 2-5 Sequential Workflows（工程を分解して直列化）
- 2-6 Multi-Agent Collaboration（役割分担・並列）
- 2-7 パターンの組み合わせ方（極限起動＝Reflection×Multi-Agent×Planning）

## L3 — Claude Code 完全習得（あなたの主戦場）
- 3-1 CLAUDE.md とメモリ階層（何を書き、何を書かないか）
- 3-2 MCP：外部サービス接続の仕組みと実装
- 3-3 サブエージェント：分業・並列・モデル最適化
- 3-4 Hooks：保存時検証・通知・自動化
- 3-5 スキルとスラッシュコマンドの設計
- 3-6 権限モードと承認設計（acceptEdits / auto / ask）
- 3-7 /effort /plan /context /rewind の使い分け
- 3-8 第二の脳の運用（毎晩整理・週次チェック）

## L4 — 自動化・オーケストレーション（実務で差がつく）
- 4-1 ヘッドレス実行（claude -p）とCI（GitHub Actions）
- 4-2 自動化パイプラインの設計（毎朝の配信＝実例）
- 4-3 A2A（Agent-to-Agent）：エージェント同士の連携プロトコル
- 4-4 RAG：自社データをベクトル検索で読ませる
- 4-5 Agent SDK でカスタムエージェントを作る
- 4-6 コスト管理：モデル選択・トークン設計・キャッシュ

## L5 — 最前線・半歩先（毎週の"特別編"で更新）
- 5-1 最新モデル動向（Fable 5 / Opus 4.8 / 画像・動画生成AIの今）
- 5-2 「業務OS化」：使うほど賢くなる仕組みの作り方
- 5-3 事業へのAI実装：どこを自動化し、どこに人を残すか
- 5-4 これから来るもの（コンピュータユース・自律エージェント経済）
- 5-5 情報の追い方：誰をフォローし、何を無視するか（ノイズ耐性）

---

## 運用ルール（`/lesson` 用）
- 1日1テーマ。既知なら「確認クイズだけ」にして次へ
- L5は週1で差し込む（最新リサーチして届ける＝鮮度で飽きさせない）
- あなたの事業（SNS運用・米沢・受注）に必ず接続する（抽象で終わらせない）
- 毎回、翌日の予告（cliffhanger）で終える
