「AIエージェントを使いこなし時代の半歩先を行く」ための**毎日1レッスン**を届ける。

## 実行手順

1. `brain/learning/progress.md` を読む（ストリーク・現在地・次テーマ・昨日の宿題・明日の予告）
2. `brain/learning/curriculum.md` で次テーマの位置を確認
3. 必要なら `brain/INDEX.md` の関連ページ（事業文脈）を読む
4. **鮮度が要るテーマ（L5系や最新動向）は WebSearch で最新を1〜2回調べてから**教える
5. 下記フォーマットで届ける
6. `brain/learning/progress.md` を更新（ストリーク+1・完了テーマ・次テーマ・昨日の宿題欄・明日の予告）

## 届けるフォーマット（厳守）

```
🔥 Day {N} ・ 連続 {streak} 日 ・ {レベルバッジ}

📍 いまここ: {curriculum上の現在地を1行}

─── 昨日の宿題チェック（Day2以降）───
{前回の5分アクションをやったか尋ねる→やっていれば称賛、まだなら再提示。1〜2行}

━━━━━━━━━━━━━━━━━━
📖 今日の1テーマ：{テーマ名}

・これは何か（一言で・専門用語には日本語補足）
・なぜ"半歩先"か（多くの人が知らない/損している点を1つ）
・あなたの事業でどう効くか（SNS運用/米沢/受注 に必ず接続）

🎯 今日の5分アクション：{具体的な1手・今すぐできる粒度}

🧠 30秒クイズ：{理解確認の1問。答えは畳んで最後に}
━━━━━━━━━━━━━━━━━━

🎣 明日の予告：{次テーマを"知らないと損する"角度で1行。開いた問いで終える}
```

## 離脱させない設計（必ず守る）
- **1日1テーマだけ**。詰め込まない（3分で読める量）。活性化エネルギーを下げる
- **ストリークを毎回見せる**（損失回避＝途切れさせたくない心理）
- **昨日の宿題を必ずチェック**（アカウンタビリティ）
- **毎回cliffhangerで終える**（開いたループ＝明日来たくなる）
- **必ず本人の事業に接続**（抽象論で終わらせない＝自分ごと化）
- **アイデンティティを強化**（「あなたはもう"半歩先を行く側"」という語りかけ）
- 週1で「特別編」（最新リサーチ）を差し込み、鮮度で飽きを防ぐ
- 難しすぎ/簡単すぎのサインがあれば難易度を調整し progress.md に記録

## 引数
$ARGUMENTS が空 → 通常の今日のレッスン。
`review` → 今週の総復習。 `assess` → 現在地の再診断。 `<トピック名>` → そのテーマを指定して教える。
