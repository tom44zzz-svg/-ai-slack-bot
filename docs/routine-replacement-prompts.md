# Routine 差し替え用プロンプト（2026-08-02）

`docs/routine-audit-2026-08.md` の推奨に沿って、事業コンテキストの直書きを
`brain/` 参照に置き換えた短縮版。**Routine編集画面のプロンプト欄に丸ごと貼り替える。**

置き換えの効果:
- 数字が変わったとき **`brain/` の1箇所を直せば全Routineに効く**（今までは5箇所）
- プロンプトが短くなる＝毎回の入力トークンが減る
- 陳腐化した数字がRoutineに埋め込まれたまま残る事故がなくなる

⚠️ 貼り替えるRoutineは **`allowed_tools` に `Read` が必要**（brain/ を読むため）。
GGG週次・月次と週次ショート動画は元から Read が入っている。
