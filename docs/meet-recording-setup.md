## 全部まとめてオンにする（★こちらが先）

**予定を1件ずつやる必要はありません。1回で以後すべてに効く設定があります。**

**meet.google.com → 右上の歯車（設定）→ 左メニュー「会議の記録」
→ 「自分が主催者の予定された会議のすべてが対象」を選ぶ**

同じ画面に **「Gemini でメモを生成する」「会議を文字起こし」「会議を録画」** が並びます。
**3つともオンに。**

今後30日の Meet は15件で、**確認できたものは全部あなたが主催**なので、これ1回で全件入ります。

> 📌 未確認: この「すべてが対象」が**メモだけでなく録画にも効くか**は、
> 出典で確認できたのが自動メモ作成のぶんだけです。画面を見て3つとも設定できるか確かめてください。
> 3つ揃っていなければ、揃わなかったぶんだけ下の「予定ごと」でやります。

**効くのはあなたが主催の会議だけです。** 他人主催の会議には入りません。

## 予定ごとにやる（上で足りなかったぶん）

Google カレンダーで予定を開く
→ **ビデオ通話オプション（歯車マーク）**
→ 左の **「会議の記録」**
→ **「会議を録画」にチェック**（文字起こし・メモも同じ画面にあります）
→ **保存**

これで**主催者が入室した時点で録画が始まります**。参加者の画面には
「この会議は録画されています」と出るので、黙って録る形にはなりません。

> この画面の名前は検索で確認したもので、Google の公式ヘルプはこの環境から開けませんでした
> （`support.google.com` が遮断されている）。**呼び名が多少違っても「歯車 → 会議の記録」に辿り着けば正解です。**

## 外部ツール（tl;dv 等）は要るか → **要りません**

最初に tl;dv を勧めましたが、**Google 純正でできるなら、そちらが上です。**

| | Google 純正 | tl;dv |
|---|---|---|
| 追加の登録 | **不要** | 必要 |
| 会議に知らない参加者が増える | **増えない** | ボットが参加者として入る |
| 文字起こし | **付く**（実績あり） | 付く |
| 保存先 | **自分の Drive** | 相手のサーバー |
| AI要約 | 会議メモ機能（プランによる） | 無料は月10件まで |
| Claude から読めるか | **読める**（Drive コネクタで既に接続済み） | コネクタの追加接続が必要 |

**決め手は最後の行です。** Drive コネクタはもう繋がっているので、
`Meet Recordings` の文字起こしを**私が今すぐ読めます**。実際、上の表はそうやって作りました。
新しくアカウントを作る理由がありません。
