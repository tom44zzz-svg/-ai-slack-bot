## 結論を先に

定期タスクは **8件・月79回**。禁書系3件を止めても **44回（−45%）にしかならない**。
無駄遣いの本体は**回数ではなく「1回あたりの重さ」**のほうにある。

だから順番はこう：

| 順 | やること | 効くところ | 対象 |
|---|---|---|---|
| **1位** | 毎日レッスンを「毎回新規セッション」に | **唯一、放置すると悪化し続ける**無駄が止まる | 1件 |
| **2位** | 全Routineでコネクタを全部オフ | 1回あたり **約167個**のツール定義が消える | 全件 |
| **3位** | 禁書系3件を止める | 実行回数 79 → 44回/月 | 3件 |

## ① 毎日レッスンを「毎回新規セッション」に　★最優先

**Routine「AIエージェント習得 毎日レッスン」**（`trig_01Bzx6bCAmDgebAw4PxfNYZN`）

```
persist_session: true
persistent_session_id: session_01R5bjwdWV9fT48FNsVsAh6U
```

**毎日この同じセッションに書き込み続けている。** 32日分が1本に積んであり、
翌日はその全部を読み直してから始まる。**日が経つほど1回が重くなる。**
「クラウドコードがすぐいっぱいになる」の直接原因はこれ。

→ 編集画面で **「毎回新しいセッションで実行」に変更**。

**ストリークは途切れません。** 学習履歴は `brain/learning/progress.md` に
毎回コミット済みなので、セッションを切っても現在地は失われない。

## ② コネクタを全部オフ　★全件

添付されているのは Canva / Notion / Slack / Gmail / Google Calendar / Google Drive / vidIQ / freee。
接続中のツール定義を数えると **約167個**：

| | | | |
|---|---|---|---|
| vidIQ 49 | Canva 31 | Notion 28 | Gmail 16 |
| Slack 13 | freee 13 | GCal 9 | GDrive 8 |

**どれも `allowed_tools` に入っていないので、1つも呼べません。**
毎回読み込まれて、使われずに捨てられている。**外して失うものはありません。**

→ 各Routineの編集画面で **コネクタのチェックを全部外す**。
※ 将来 Notion や Slack に投稿させたくなったら、そのRoutineにだけ1個足す。

> 📏 **数字について正直に**：167個は接続中コネクタから数えた実数。
> トークン量は測っていません（Routineの実行ログを見る手段がこちら側に無い）。
> 参考値として、外部調査では「5サーバー58ツールで約55,000トークン」という実測があります。
