# Google カレンダー運用ルール（2026-09-05 本人指定）

毎朝の Routine「カレンダー整備」がこのルールで動く。**手で直すときも同じ基準**。

## 1. 赤にする（colorId 11 = トマト）

**他人と時間を約束している予定**、または**開始時刻が動かせない予定**。

- 対象の目印: 会議URL（Meet / Zoom）がある／タイトルに MTG・面談・打ち合わせ・面接・グルコン・講座・公演・コンサート・イベント・消防
- 対象外: タイトルに【仮】・候補・締切・期限／終日の予定／自分だけの作業ブロック
- **繰り返し予定は自動では変えない**（親を変えると全回に効くため）。一覧に出して本人が決める

## 2. 移動ブロックを前後に入れる（colorId 8 = グラファイト）

**物理的な場所で行う予定**が対象。オンライン（会議URLあり）は対象外。

- 目印: 撮影・現地・来店・会場・店名・住所が入っている
- 前後それぞれ **30分** の `🚗 移動（→X）` / `🚗 移動（X→）` を入れる。本文に「自動追加・所要時間は仮」と書く
- **すでに前後に「移動」があればスキップ**（本人が手で入れている例: カット、セリジェ、ラグラス）
- 【仮】・候補は対象外。確定してから
- 30分は仮。遠方（仙台など）は本人が伸ばす

## 3. GGG カレンダーの意味の無いブロックを消す

`案件A_25h` `案件B_25h` `案件C_20h` のような **`案件X_NNh` 形式のプレースホルダ**は削除。
（2026-06-20 に作られた仮置き。2026-09-05 に7件削除済み）

## 4. 報告の仕方

- 変更が無い日は「変更なし」の1行で終える
- 迷ったものは変えずに「要確認」として出す
