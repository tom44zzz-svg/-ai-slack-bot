### ⛔ カレンダー側から消してはいけない（2026-09-14 に実証）

**Zoom↔Google カレンダーの連携は双方向。カレンダーの予定を消すと、Zoom のミーティング本体も消える。**

根拠: 2026-09-14 に3件をカレンダーから削除したところ、**それぞれの約1分半後に
Zoom から `Your meeting - ○○ has been deleted` の通知メールが届いた**（20:46:10 / 20:46:55 / 20:48:12 Z。
削除操作は 20:44:35 / 20:45:26 / 20:46:37 Z）。定例で使い回していたリンクが3本とも失われた。

**正しい順番:**

1. **Zoom の設定 → カレンダーと連絡先の連携 → 解除**（原因を止める。ここが先）
2. **Zoom 側で**不要なミーティングを整理する。カレンダーの予定は連携解除後に自然に外れる
3. カレンダーから消す必要があるときは、**それが Zoom 由来でないことを確認してから**
   （`description` に `zoom.us` が入っていれば Zoom 由来）

### 消してしまったときの復旧

**7日以内なら会議IDごと戻せる。** <https://us06web.zoom.us/meeting/trashcan/list>（最近削除したアイテム）。
7日を過ぎると完全消去され、作り直しになる＝**会議IDが変わり、配布済みのリンクが全部死ぬ**。

削除通知メールは `no-reply@zoom.us` から件名 `Your meeting - ○○ has been deleted` で届き、
本文に会議IDが載っている。**復旧に必要な情報はここから拾える。**

⚠️ **復元しただけでは「定期開催」に戻らない。** 削除時点の姿（＝連携が時刻を埋めた、

**Zoom の Web で「定期ミーティング」＋「再実施＝固定時刻なし」に直す必要がある**
（デスクトップアプリにこの選択肢は無い）。手順は `docs/your-turn-manual.md`。
