## 5. Zoom 連携で勝手に入った予定（2026-09-14 の事故）

Zoom の「カレンダーと連絡先の連携」を繋いだ瞬間、**33秒の間に3件**がメインカレンダーに入った。

見分け方（3つとも揃う）:

- `creator` は本人だが、`created` が連携した時刻に固まっている
- **開始時刻が「連携した瞬間」**（例: 21:37:02 / 21:37:13 / 21:37:35）。予定として入れた時刻ではない
- 所要時間が **40分 / 60分** ちょうど＝ Zoom の既定値

→ これは **「固定時刻なしの繰り返しミーティング」**（定例で同じリンクを使い回すやつ）が
同期されたもの。時間が決まっていないので、同期が「今」を埋めて1回きりの予定として置いた。

**Zoom 側のミーティングは消えていない。** 定例リンクとしては今までどおり使える。
汚れたのはカレンダーだけ。

### 消す前に必ずやること

1. **Zoom 側の同期を先に切る**（Zoom の設定 → カレンダーと連絡先の連携）。
   切らずに消すと、同期が同じものをまた入れる可能性がある
2. 会議 ID とパスコードを控える。**このリポジトリは public なので、控えはここに書かない**
3. そのうえでカレンダーの3件を消す

### 既存の定例は無事か

**無事。** `orderBy=lastModified` で全件を並べて確認したところ、
この3件を除くと**最も新しい更新が 2026-08-12** で、繰り返し予定は1件も書き換わっていなかった。
連携は「足した」だけで、既存を壊してはいない。
