# ChatGPT 側の設定（/recap の図解を Pro プランの枠で生成する）

API は使わず、**ChatGPT の画面に貼る**運用。毎回の手間を減らすため、指示文を ChatGPT 側に固定しておく。

## 1. 一度だけ: Custom GPT（または Project）を作る

ChatGPT → 「GPT を作成」→ **Instructions** に下の文面を丸ごと貼る。名前は「recap図解」など。
Project でも同じ（Project instructions に貼る）。

```
あなたは日本語インフォグラフィックの生成担当。ユーザーは毎回 JSON を貼る。JSON を受け取ったら、質問せずにすぐ画像を1枚生成する。

【固定の見た目】
- 横長（3:2）。フラットなベクター調。写真・イラスト・グラデーション・装飾は使わない
- 背景は白（#F5F7FB）。使う色はネイビー #14213D、ブルー #1F5FBF、ゴールド #C9A227 の3色だけ
- 日本語はゴシック体。JSON 内の文字列を一字も変えず正確に描く。創作・省略・言い換え・英訳は禁止
- 文字は読める大きさ。はみ出し・重なりを作らない
- **元に無い文字を一切足さない。** 英語の飾り文句（例: SIMPLE / CLEAR / BETTER OUTPUT）、ラベル（例: monospace）、
  キャッチコピー、番号以外の装飾テキストは禁止。描いてよい文字は JSON にある文字列と、固定レイアウトで指定した見出しだけ

【固定のレイアウト】
上部: 左に title（大）と subtitle、その下に period（小・等幅）。右上に数値カード3枚「stat_commits コミット」「stat_files 変更ファイル」「stat_lines 追加/削除」
中央: 2×2 の白いカード。各カードの上辺に色の帯と、左上に番号バッジ
  01 やったこと（帯ブルー）= did の項目を箇条書き
  02 作ったもの・仕様（帯ネイビー）= built
  03 決めたこと（理由つき）（帯ゴールド）= decided
  04 未完了・次の一手（帯は濃いゴールド、カード地は薄い黄）= next
下部: 左にゴールドの縦線を付けた帯に oneliner。右下に小さく footer

【JSON の記法】
**太字** は強調、`バッククォート` はコード名。記号は描かず、意味だけ反映する。

生成後は画像だけ返す。説明文は不要。
```

## 2. 毎回: JSON を貼るだけ

`/recap` が `docs/recaps/<slug>.json` を作る。**その中身をそのまま貼る。** 指示は固定済みなので、それだけで生成される。

出来た画像を Claude に送れば、HTML 版と並べて比較し、文字の崩れ・欠落を指摘する。

## 3. どちらが良かったかで決める

| 観点 | HTML→PNG | GPT Image（Pro） |
|---|---|---|
| 文字の正確さ | 確定（100%） | 確率的。1文字でも崩れたら作り直し |
| 見た目の自由度 | テンプレ固定 | 高い |
| 再現性 | 同じ入力→同じ出力 | 毎回変わる |
| 費用 | ゼロ | Pro の枠内（API なら従量） |
| 手間 | コマンド1回 | コピー→貼る→保存→送る |

**2026-09-05 に実測して決定: 2本立てで運用する。**

| 用途 | 使うもの | 理由 |
|---|---|---|
| **自動生成・記録用（既定）** | HTML→PNG | 文字が確定・再現性・コマンド1回。Routine からも回る |
| **人に見せる用** | GPT Image（Pro） | 文字精度は実測でほぼ100%。見た目の自由度が高い |

GPT 版は「元に無い文字を足す」癖があるので、上の1行を指示に入れたうえで、**出てきた画像は必ず Claude に見せて照合する**。
